# Chapter 11 Examples: Executive and Strategic Prompts

This directory contains practical examples from Chapter 11, demonstrating AI-augmented executive decision-making and strategic planning techniques that accelerate high-level analysis and improve decision quality.

## Examples Included

- **enterprise-market-analysis.md**: Comprehensive market analysis for strategic planning
- **strategic-option-evaluation.md**: Framework for evaluating multiple strategic alternatives
- **scenario-planning-framework.md**: Multi-scenario strategic planning methodology
- **executive-decision-support.md**: Systematic approach to complex executive decisions
- **organizational-development-strategy.md**: Strategic frameworks for organizational alignment

## Key Learning Outcomes

These examples demonstrate how to:
- Conduct comprehensive market analysis that informs strategic decisions
- Evaluate strategic options systematically with quantitative and qualitative factors
- Develop scenario-based planning that maintains strategic flexibility
- Create decision-making frameworks that improve both speed and quality
- Align organizational development with strategic objectives

## Usage Guidelines

Each example includes:
- **Context**: Strategic challenge and decision-making requirements
- **Prompts**: Exact text used for executive-level AI collaboration
- **AI Outputs**: Complete strategic analysis and recommendations
- **Analysis**: Why each approach works for executive audiences
- **Adaptation Templates**: How to customize for your strategic context
- **Success Metrics**: Measurable improvements in decision speed and quality
